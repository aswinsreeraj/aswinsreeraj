### 1. [ARDA — AI Agent Execution & Governance Platform](https://github.com/aswinsreeraj/arda) *(Flagship)*
*A multi-tenant microservices platform for running and governing autonomous AI agents with strict security guardrails, durable workflows, and precedent reliability scoring.*

<p align="left">
<img src="https://img.shields.io/badge/Go-00ADD8?style=for-the-badge&logo=go&logoColor=white" />
<img src="https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white" />

<img src="https://img.shields.io/badge/pgvector-336791?style=for-the-badge&logo=postgresql&logoColor=white" />
<img src="https://img.shields.io/badge/Temporal-000000?style=for-the-badge&logo=temporal&logoColor=white" />
<img src="https://img.shields.io/badge/Vault-000000?style=for-the-badge&logo=vault&logoColor=white" />
<img src="https://img.shields.io/badge/MCP-101820?style=for-the-badge&logo=anthropic&logoColor=white" />
<img src="https://img.shields.io/badge/Redpanda-FA243C?style=for-the-badge&logo=redpanda&logoColor=white" />
</p>

- **10-Step ToolGateway & MCP**: Enforces strict tool boundaries with JSON Schema Draft-07 validation, SSRF private IP blocking, SHA-256 idempotency locks, and human approval gates.
- **Reliability Assessment**: Dedicated Python microservice running semantic similarity via PostgreSQL `pgvector` HNSW (`SET LOCAL hnsw.iterative_scan = strict_order`) to retrieve historical tool failures.
- **Durable Orchestration**: Built with Temporal workflows to survive crashes during multi-step agent tool execution.
- **BYOK Key Custody**: Per-tenant API secret isolation backed by HashiCorp Vault KV v2.
- **Integrity Verification**: Cross-language HMAC-SHA256 signature verification over streaming Redpanda feedback events.

*A full-stack ticketing platform built to handle high-contention ticket inventory, multi-party escrow wallets, and real-time financial tracking.*

<p align="left">
<img src="https://img.shields.io/badge/Go-00ADD8?style=for-the-badge&logo=go&logoColor=white" />
<img src="https://img.shields.io/badge/Gin-008ECF?style=for-the-badge&logo=gin&logoColor=white" />

- **Concurrency-Safe Reservations**: Optimistic concurrency control via version CAS and conditional inventory updates with automatic 1-minute expiration holds.
- **Escrow Wallet Ledger**: Multi-bucket financial ledgers using PostgreSQL `FOR UPDATE` row-level locks to coordinate balances, fees, organizer payouts, and refunds without double-spends.
- **Late-Capture Payment Recovery**: Automated Razorpay API source refunds when payment verification succeeds after reservation timeout.
- **Full-Stack Experience**: Clean Architecture Go backend paired with a React 19 / TypeScript UI with Zustand state management and single-use QR ticket check-ins.

### 3. [Tenome Micro — Distributed Search & Web Crawling Platform](https://github.com/aswinsreeraj/tenome-micro)
*A 4-service event-driven microservices architecture combining concurrent crawling, local LLM summarization, and end-to-end observability.*

<p align="left">
<img src="https://img.shields.io/badge/Go-00ADD8?style=for-the-badge&logo=go&logoColor=white" />
<img src="https://img.shields.io/badge/gRPC-244c5a?style=for-the-badge&logo=grpc&logoColor=white" />
<img src="https://img.shields.io/badge/Apache_Kafka-231F20?style=for-the-badge&logo=apachekafka&logoColor=white" />
<img src="https://img.shields.io/badge/Dragonfly-FF4F00?style=for-the-badge&logo=redis&logoColor=white" />
<img src="https://img.shields.io/badge/SQLite-003B57?style=for-the-badge&logo=sqlite&logoColor=white" />
<img src="https://img.shields.io/badge/Ollama-000000?style=for-the-badge&logo=ollama&logoColor=white" />
<img src="https://img.shields.io/badge/OpenTelemetry-000000?style=for-the-badge&logo=opentelemetry&logoColor=white" />
</p>

- **Concurrent Web Crawler**: Bounded 100-slot / 4-worker HTML crawl engine with an in-memory inverted index avoiding full table scans.
- **Kafka Claim-Check Architecture**: Decouples search, AI summarization, and notification services via event choreography with jittered Dead Letter Topic (DLT) retries.
- **Local AI Inference**: Offline semantic page summaries using local Ollama (`qwen2.5:0.5b`).
- **Full Observability**: End-to-end tracing and metric collection across microservices with OpenTelemetry, Tempo, Prometheus, and Grafana.
